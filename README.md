Цей репозиторій містить виконані лабораторні роботи з дисципліни **"Інтелектуальні інформаційні технології"**. ## 📚 Огляд лабораторних робіт

### 🔹 [Лабораторна робота №1](./Lab-1/)

* **Тема:** Базові поняття CLIPS. Продукційні правила та факти.
* **Короткий опис:** Ознайомлення з середовищем CLIPS. Побудова генеалогічного дерева (родинних зв'язків) за допомогою синтаксису впорядкованих фактів та базових правил виведення (`defrule`).

### 🔹 [Лабораторна робота №2](./Lab-2/)

* **Тема:** Побудова баз знань та пошук за критеріями.
* **Короткий опис:** Моделювання астрономічної бази даних зірок. Реалізація шаблонів фактів та правил для вибірки об'єктів за заданими критеріями (спектральний клас, зоряна величина, відстань до Землі).

### 🔹 [Лабораторна робота №3](./Lab-3/)

* **Тема:** Інтерактивні експертні системи та введення даних.
* **Короткий опис:** Розширення системи пошуку зорі інтерактивним діалогом. Використання функцій читання даних `(read)` під час виконання програми для динамічного формування умов пошуку в базі знань.

### 🔹 [Лабораторна робота №4](./Lab-4/)

* **Тема:** Функції в CLIPS (`deffunction`).
* **Короткий опис:** Рефакторинг експертної системи: перехід від продукційних правил до використання користувацьких функцій `deffunction` та макросу ітерації фактів `do-for-all-facts` для більш модульного та процедурного управління пошуком.

### 🔹 [Лабораторна робота №5](./Lab-5/)

* **Тема:** Префіксна арифметика та моніторинг промислових об'єктів.
* **Короткий опис:**
   1. Перетворення складних інфіксних арифметичних виразів у префіксні нотації CLIPS.
   2. Розробка системи моніторингу стану 10 промислових датчиків з використанням `deftemplate`, `find-all-facts` та автоматичним генераторам сповіщень про несправності.

## 🛠 Інструкція з запуску

Для запуску програм вам знадобиться встановлене середовище **CLIPS IDE** (або консольна версія `clips`).

### Загальний алгоритм запуску файлу `.clp`:

1. Відкрийте **CLIPS IDE** (або запустіть команду `clips` у терміналі).
2. Завантажте необхідний файл проєкту:
```clips
(load "labX/filename.clp")
```

3. Скиньте стан середовища для завантаження початкових фактів (`deffacts` / `deftemplate`):
```clips
(reset)
```

4. Запустіть виконання правил або викличте потрібну керуючу функцію:
* Для виведення через правила:
```clips
(run)
```

* Для виклику інтерактивних функцій (наприклад, у Лаб 4):
```clips
(find-stars)
```
